# KafkaLens Feature Backlog

## Planned

### Scope search to message timestamp
**"Scope to ±5 min"** button in the message detail drawer.  
Clicking it pre-fills the From/To Timestamp fields with a ±5 minute window around the selected message's timestamp and closes the drawer, ready to re-search.  
**Use case:** Find 1–5 representative messages that look right, then narrow the search window around them without manually copying timestamps.
